# 말로 캐드 3D 모델링 계획

사용자 방향: **캐드로 3D를 구성하고, 그것으로 모델링까지 한다.** 2D 도면은 그 바탕이다.
방식은 CAD와 같다 — 바닥에 2D로 그린 선을 밀어올리고, 입체끼리 합치고 빼서 모델을 만든다. 말(AI)로도 같은 명령을 쓴다.

## 데이터 약속 (모든 단계 공통)

- 단위 mm, Z가 위쪽. 층(`doc.levels`)의 바닥 레벨이 각 요소의 기준 높이.
- 입체는 `doc.ents`의 한 요소: `{ type:'solid', kind, floor, layer, z, h, ... }`
  - `kind:'box'|'ext'` — `pts` 바닥 윤곽(닫힌 다각형)
  - `kind:'cyl'` — `cx, cy, r`, `r2`(윗면 반지름, 0이면 원뿔)
  - `kind:'sph'` — `cx, cy, r`, `z`=중심 높이
  - `z` = 층 바닥에서 밑면까지, `h` = 높이(항상 양수로 정리)
- 2D 화면에서는 바닥 윤곽으로 보이고, 이동·복사·회전·대칭·축척·지우기·실행취소·서버 저장이 2D 요소와 똑같이 된다.
- 내보내기: DXF는 3DFACE, OBJ·STL은 삼각형 면.

## 1단계 — 3D 화면과 기본 입체 (완료, `cad-3d.js`)

- 도면 화면을 3D로 전환: 리본 「3D」 탭, 왼쪽 위 「[보기 방향][보기 방식]」, 방위 표시(북·동·남·서 → 그 방향 입면, 가운데 → 평면, 두 번 누르기 → 남서 등각)
- 마우스: 왼쪽 끌기 돌려보기, 가운데·오른쪽·Shift 끌기 이동, 휠 확대, 오른쪽 클릭 Enter, 가운데 두 번 → 전체
- 보기 방식: 2D 선 / 와이어프레임 / 음영 / 음영+모서리 / X-레이, 원근 켜기·끄기
- 명령: `3DORBIT`(3DO·3D) `PLAN` `VIEW` `VSCURRENT`(VS) `ELEV` `BOX` `CYLINDER`(CYL) `CONE` `SPHERE` `EXTRUDE`(EXT) `PRESSPULL`(PRESS·PP) `OBJOUT` `STLOUT`
- 3D 화면에서도 명령 그대로: 클릭 = 작업 평면(층 바닥 + 작업 높이) 위의 점. 입체 윗면을 찍으면 그 높이에서 시작. 꼭짓점·중간점·중심 스냅(윗면·밑면 모두).
- 높이는 숫자 입력 또는 3D 화면에서 마우스를 올려 클릭(10mm 단위).
- 벽·기둥·슬라브·설비·창·문은 층고대로 세워 보임(창·문 구멍은 2단계).
- AI: `add`에 `type:'solid'`, `ops`에 `EXTRUDE`·`VIEW3D`·`PLAN`.

## 2단계 — 합치기·빼기 (다음)

- `UNION` `SUBTRACT` `INTERSECT` — manifold-3d(Apache-2.0, WebAssembly)로 계산.
- 결과는 `kind:'mesh'` 입체: `{ verts:[[x,y,z]...], tris:[[i,j,k]...] }` (층 바닥 기준 좌표). 원래 입체는 `src`에 남겨 다시 계산할 수 있게.
- 벽에 창·문 구멍을 자동으로 뚫기(벽 입체 − 창·문 상자).
- `REVOLVE`(회전체), `SWEEP`(경로 따라), `LOFT`(단면 잇기).
- 3D에서 면 고르기(누르고 당기기를 옆면에도).

## 3단계 — 작업 평면(UCS)과 3D 편집

- `UCS` — 면을 찍어 그 면 위에 그리기(경사 지붕·벽면). 2D 명령이 그 평면에서 동작.
- `3DMOVE` `3DROTATE` `MIRROR3D` `3DARRAY`, `SLICE`(자르기), `SHELL`(두께 주기), `FILLETEDGE`.
- 3D 그립(높이·윗면 끌어서 바꾸기).

## 4단계 — 도면 뽑기·내보내기

- 3D 모델에서 평면·입면·단면 자동 생성(`SECTIONPLANE`, `FLATSHOT`), 숨은선 처리.
- glTF 내보내기, DWG에 메시로 넣기.
- 배치(출력)에서 3D 뷰포트.

## 5단계 — 말로 모델링

- "2층 슬래브 두께 200으로", "계단 넣어줘", "지붕 경사 30도로" 같은 요청을 입체 명령으로.
- 건축 요소(벽·슬라브·계단·지붕)를 입체 규칙으로 자동 생성.
